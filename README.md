# VAT Identifier Discovery

Technical challenge for the Data Assets Intern position at Veridion.

## Overview

This project investigates whether UK VAT identifiers can be discovered from publicly available sources and reliably matched to the correct legal entity.

The investigation covers:

- Initial research and understanding of the problem
- VAT discovery sources
- Companies House and HMRC
- Third-party VAT lookup services
- Validation and false-positive examples
- Proof of concept
- Considerations for scaling the solution

## Project

The full investigation is available in:

**[VAT Identifier Discovery.docx](VAT%20Identifier%20Discovery.docx)**

## Key conclusion

The main challenge is not simply finding a valid VAT number, but reliably connecting it to the correct legal entity.

A multi-source discovery process combined with independent HMRC verification appears to be the most promising approach.
